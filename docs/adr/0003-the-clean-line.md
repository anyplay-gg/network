# The clean line

Superseded by [ADR 0021](0021-the-line-is-drawn-at-the-law.md).

The network never contacts Sony's servers, never uses Sony's code, keys or leaked documents, never issues tokens for a publisher's client, never stands in for a publisher's servers, and never bypasses anti-cheat or account checks. Games that need any of that stay offline. We accept losing those games because the project only lasts if no rights holder has a reason to stop it. Interoperability with games the player owns is defensible; impersonating someone else's service is not. Formats are therefore learned only by observing games the player owns, as the interoperability provisions of Article 6 of the EU Software Directive allow, and written down as our own specifications.

## Consequences

- Some popular games, such as those that sign in to Microsoft, PlayFab or EA services, will not play online on the network.
- The network is never presented as a replacement for PlayStation Plus, and its names carry no platform trademarks.
