# Trophy records, not trophy texts

The cloud keeps a record per earned trophy: the title ID, the trophy's number within the game, its grade and the time. A trophy's name, description and picture come from the game's own files and stay on the PCs of players who own the game; each launcher shows them from its own copy. So the cloud stores no publisher content, a profile page never shows game art, and the records still give counts, grades, rarity and comparisons between friends. The records use the network's title IDs and never a platform's trophy set IDs, and nothing about them is sent to a platform.

## Considered options

- Uploading names and pictures with the records: friends without the game would see them, but the cloud would host every game's trophy texts and art, which belong to their publishers.
- Keeping trophies on the PC only: no rarity, no comparison, no feed.
